# 🐻 Ratan Mahal Wildlife Sanctuary

### Wildlife Conservation & Tourism Web Platform

A modern, responsive, full-stack web application developed to showcase the natural beauty, wildlife, biodiversity, and tourism information of **Ratan Mahal Wildlife Sanctuary, Gujarat, India**.

The platform provides an interactive experience for visitors while offering an administrative dashboard for managing website content.

🌐 **Live Website:** https://ratan-mahal-wildlife-sanctuary-9fv5.vercel.app/

## 🚀 Project Overview

Ratan Mahal Wildlife Sanctuary is a MERN-stack web application designed to make wildlife and tourism information easily accessible through a modern digital platform.

The project combines responsive frontend design, REST APIs, database integration, authentication, administrative content management, and search engine optimization.

## 💻 Local Installation

### 1. Clone the repository

```bash
git clone https://github.com/yashpuvar/ratan-mahal-wildlife-sanctuary.git
cd ratan-mahal-wildlife-sanctuary
```

### 2. Install frontend dependencies

```bash
cd frontend
npm install
npm run dev
```

### 3. Install backend dependencies

Open another terminal:

```bash
cd backend
npm install
npm start
```

Configure the required environment variables for MongoDB, authentication, and other integrations before running the application.

Never commit `.env` files or private credentials to GitHub.
